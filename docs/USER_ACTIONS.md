# Actions Required From Praveena

The code, official data audit, benchmark construction, deterministic scoring, and tests
are automated. These steps require your personal account or scholarly approval.

## Before API execution

1. Choose exact model IDs after confirming free-tier availability.
2. Copy `configs/models.example.yaml` to `configs/models.local.yaml`.
3. Add the exact IDs. Do not use vague aliases such as “latest” where a dated version exists.
4. Put API keys in shell environment variables. Never paste keys into YAML, Git, the paper,
   or a screenshot.
5. Review and approve `docs/preregistration.md`.
6. Create an OSF registration or equivalent timestamped record under your own account.

## After experiments

1. Confirm that you personally understand and approve every claim in the manuscript.
2. Decide author order and obtain every co-author's approval.
3. Complete OpenReview profile requirements and conference checklists.
4. Disclose AI assistance according to the active conference policy.
5. Submit the anonymized manuscript and supplement from your account.

## Never do

- Do not call smoke-test outputs “results.”
- Do not remove cases after seeing unfavorable model behavior.
- Do not invent missing API runs or numerical findings.
- Do not describe the dataset as denied-applicant data.
- Do not claim A* acceptance is guaranteed.
